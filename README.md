## About me

I am an **Electrical Engineer** working at the intersection of **control systems, AI/ML, embedded systems and applied research**.

My work has evolved from **power electronics and converter simulation** into **networked cyber-physical systems**, where sensing, estimation, communication and control have to operate as one system.

Today, I am developing **GlucoPilot / InsulinPumpOS** — a research-oriented closed-loop insulin delivery platform combining an embedded pump controller, CGM-driven control, MQTT networking, real-time telemetry, automatic meal detection, sensor-fusion-based exercise detection and supervisory monitoring.

I am particularly interested in problems where **physical models + data-driven methods + real-time computation** meet: nonlinear control, intelligent estimation, sensor fusion, networked control systems, and physics-informed learning.

## A few principles behind my work

> **Model the physics. Measure the system. Fuse the information. Close the loop.**

I like engineering problems where a solution is not just an algorithm, but a **complete system**: sensing → computation → communication → decision → actuation → feedback.

That is the thread connecting my earlier power-electronics work with my current research in intelligent, networked control systems.
